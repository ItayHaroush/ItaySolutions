# External proposal approvals — implemented in Buildix

The Laravel backend lives in Buildix, not in PortfolioReact.

## Endpoints

POST `/api/proposals/prepare` — create client + quote  
POST `/api/proposals/attachment` — upload full itaysolutions PDF as quote attachment  
POST `/api/proposals/approve` — sign + attach signed PDF + regenerate Buildix PDF  
GET/POST `/api/proposals/branding` — logo + business name sync

Production base: https://app.buildix.site/api/proposals/

## PDF attachment (signed only)

The full itaysolutions proposal is attached **only after the client signs and approves**
(`POST /api/proposals/approve` with `proposalHtml`). It is **not** attached when creating
the quote or when the owner opens the send page.

Buildix renders HTML with Dompdf + `DompdfHebrew` (same as quote PDFs), stores it as
`attachment_path`, then merges it at the end of the quote PDF.

## Deploy on VPS

```bash
cd backend
git pull
php artisan migrate
# restart php-fpm / queue if needed
```

`.env`:
```env
BUILDIX_EXTERNAL_PROPOSAL_OWNER_EMAIL=itay@itaysolutions.com
BUILDIX_EXTERNAL_PROPOSAL_NOTIFY_EMAIL=itay@itaysolutions.com
BUILDIX_EXTERNAL_PROPOSAL_ORIGINS=https://www.itaysolutions.com,https://itaysolutions.com,http://localhost:8765,http://127.0.0.1:8765
```

## Register a new proposal template

Each `buildixTemplateKey` in `proposals-registry.json` must exist in Buildix
`backend/config/buildix.php` under `external_proposal.templates`
(e.g. `takeeat-hatzarfatiya-2026`, `private-branded-orders-2026`,
`social-media-management-2026`, `digital-monthly-bundle-2026`).
Until registered, `/api/proposals/prepare` returns `422 Unknown proposal template`.
Use **צפייה מקומית** in `/proposals/` for local preview without Buildix.

After adding a template in Buildix:
```bash
cd backend
git pull   # or deploy the config change
# no migration needed for config-only templates
# restart php-fpm / clear config cache if used:
php artisan config:clear
```

## Connect PortfolioReact

`proposals/proposal-backend-config.js`:
```javascript
window.PROPOSAL_ATTACHMENT_URL = "https://app.buildix.site/api/proposals/attachment";
window.PROPOSAL_TURNSTILE_CONFIG_URL = "https://app.buildix.site/api/public/turnstile/proposal_prepare";
window.PROPOSAL_TURNSTILE_SITE_KEY = "0x4AAAAAADyOgFOmlKJsciFD";
```

`POST /api/proposals/prepare` requires Cloudflare Turnstile (`turnstile_token`).
The proposals admin panel loads the widget and sends the token automatically.
